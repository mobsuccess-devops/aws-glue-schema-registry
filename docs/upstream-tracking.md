# Upstream tracking

Every open issue and pull request on
[`awslabs/aws-glue-schema-registry`](https://github.com/awslabs/aws-glue-schema-registry),
and how this fork relates to each. Upstream has been dormant since `eed1506` (2026-08-13) —
the fork point, and still its `master` HEAD — so its open queue is the closest thing the two
repositories have to a shared backlog. This file records what the fork has shipped, what it
intends to adopt, and what it deliberately leaves aside.

Statuses:

- **Addressed** — shipped in this fork; the note links the pull request or names the
  coverage.
- **To address** — worth adopting: _planned_ when scheduled, _evaluate_ when the value or
  the fix still needs to be established.
- **Out of scope** — deliberately not pursued, with the reason. "C#", "Go" and "native"
  refer to the multi-language layer this fork removed.

Last sync: 2026-08-21, upstream at `eed1506`. Update the relevant row when a fork pull
request lands on one of these items; re-sync the whole inventory when upstream moves.
